
# ESP32 Power Monitoring System

## Project Overview
This project simulates an ESP32-based power monitoring system using Arduino code in Wokwi.

## Features
- Voltage monitoring simulation
- Current monitoring simulation
- Power calculation
- Normal and overload status indication
- LED status indicator

## Components
- ESP32 development board
- LED
- Resistor

## Formula
Power (W) = Voltage (V) × Current (A)
